# 🎓 SmartStudy: ระบบจัดการการบ้านและวางแผนการเรียนอัจฉริยะ (Multi-User Edition)

> เว็บแอปพลิเคชันสำหรับนักเรียน ช่วยจัดการการบ้านและวางแผนเวลาอ่านหนังสือด้วยระบบจัดลำดับความเร่งด่วนอัจฉริยะ พร้อมระบบสมาชิกและล็อกอินรักษาความปลอดภัย พัฒนาด้วย **Python**, **Streamlit**, **SQLite**, **Pandas** และ **Altair** สำหรับใส่พอร์ตโฟลิโอ (Portfolio) ยื่นเข้ามหาวิทยาลัย

---

## 🌟 จุดเด่นของโปรเจกต์ (Key Features)

| ฟีเจอร์ | รายละเอียด |
| :--- | :--- |
| 🔐 **ระบบล็อกอิน & สมัครสมาชิก (Authentication)** | สมัครสมาชิกและเข้าสู่ระบบ พร้อมการเข้ารหัสรหัสผ่าน **SHA-256 + Salt** เพื่อความปลอดภัย ไม่เก็บรหัสผ่านเป็น plain text |
| 👥 **ระบบแยกข้อมูลผู้ใช้ (Multi-User Isolation)** | แต่ละคนมีบัญชีของตัวเองและมองเห็นเฉพาะการบ้านของตนเองเท่านั้น (ผูก `user_id` กับตาราง `tasks`) |
| 📋 **ระบบจัดการการบ้าน** | เพิ่ม, แก้ไขสถานะ (เสร็จแล้ว/ทำใหม่), และลบการบ้าน พร้อมระบบบันทึกถาวรด้วย **SQLite** |
| 🧠 **อัลกอริทึมจัดลำดับความเร่งด่วน (Urgency Engine)** | คำนวณคะแนน **Urgency Score** จากความใกล้ของวันส่ง, ระดับความสำคัญ (1–5), และชั่วโมงที่ต้องใช้ทำ |
| 💡 **ระบบแนะนำงานอันดับ 1 (Next Best Action)** | วิเคราะห์และแนะนำอัตโนมัติว่า **"ควรทำการบ้านชิ้นไหนก่อนทันที"** พร้อมบอกเหตุผลชัดเจน |
| 📊 **แดชบอร์ดสถิติ & กราฟวิเคราะห์งาน** | แสดงภาพรวมภาระงานผ่านกราฟ **Altair** แนวนอน 100% อ่านง่ายสบายตา ไม่เอียงคอ |
| 🤖 **AI ผู้ช่วยเรียน (Chatbot)** | แชทกับสมาร์ทตี้เพื่อถามงานที่ควรทำก่อน, สรุปการบ้าน, และอธิบายบทเรียน รองรับ Gemini / Groq / OpenAI ถ้ามี API key |
| 🎨 **ดีไซน์ Dark Tech & ปุ่มฟันเฟืองตั้งค่า ⚙️** | ธีมสีดาร์กโหมดทันสมัย พร้อมปุ่มฟันเฟืองเปิดหน้าต่าง Pop-up (Modal) จิ้มเปลี่ยนสีนีออนและขนาดฟอนต์ได้สดๆ |
| 🧪 **ระบบทดสอบโค้ด (Automated Unit Tests)** | มีชุดทดสอบด้วย `unittest` ครบ 9 การทดสอบ ครอบคลุมทั้งการคำนวณวันส่ง, ฐานข้อมูล และระบบล็อกอิน |

## 🏗️ โครงสร้างไฟล์ในโปรเจกต์ (Project Structure)

โปรเจกต์แบ่งสัดส่วนการทำงานชัดเจนตามหลัก **Separation of Concerns**:

```text
SmartStudy/
├── app.py                # ส่วนติดต่อผู้ใช้ (UI), หน้าจอ Login & Register และแดชบอร์ด
├── database.py           # จัดการฐานข้อมูล SQLite (ตาราง users และ tasks) พร้อมการแฮชรหัสผ่าน
├── planner.py            # อัลกอริทึมคำนวณคะแนนความเร่งด่วนและการจัดลำดับงาน
├── chatbot.py            # ผู้ช่วยเรียน AI (โหมดในเครื่อง + Gemini/Groq/OpenAI)
├── test_planner.py       # ชุดทดสอบ Unit Test ตรวจสอบความถูกต้องของระบบและ Authentication
├── run.bat               # ทางลัดดับเบิ้ลคลิกเปิดโปรแกรมบน Windows
├── requirements.txt      # รายการไลบรารีที่โปรเจกต์ต้องใช้
└── .streamlit/config.toml# การตั้งค่าธีมสี Dark Mode และเซิร์ฟเวอร์
```

## 🚀 วิธีเปิดใช้งานโปรแกรม

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ลัด (ง่ายที่สุด)
ดับเบิ้ลคลิกที่ไฟล์ **`run.bat`** ในโฟลเดอร์โปรเจกต์ เว็บจะเปิดขึ้นมาบนเบราว์เซอร์อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
cd d:\Smartstudy
python -m streamlit run app.py
```
เปิดเบราว์เซอร์ไปที่: **http://localhost:8501**
